# 录像成品保留策略

2026-10-09 按用户要求，生产全局配置已开启 `on_record_finished.burn_delete_source: true`。通过 `PATCH /api/config` 部分更新，实时生效并写入部署配置；未重启服务，未修改直播间或硬件参数。

## 当前行为

- 录制阶段先保存原直播流（例如 FLV）。
- 录制结束后压缩为 H.265，目标视频码率 4M，保持原分辨率；有 ASS 时同次烧录。
- 成品解码、时长、音轨校验通过且全部后处理阶段成功后，删除原视频，只保留 MKV 成品视频。
- 失败、取消、校验失败，或源文件在处理期间仍有变化时保留原件。
- 用户随后确认开启 `burn_delete_ass: true`：弹幕成功烧进视频并完成全部处理后，删除同名 ASS，避免播放器自动加载外部字幕造成双层弹幕。失败时仍保留原视频和 ASS。
- 对新任务生效，不自动追溯删除旧原件；手动压缩同样遵循当前删除原视频设置。
